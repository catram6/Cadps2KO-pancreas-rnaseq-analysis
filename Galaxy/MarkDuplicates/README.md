# MarkDuplicates

PCR duplicates were removed from the aligned RNA-seq reads using MarkDuplicates.

## Purpose

MarkDuplicates was used to identify and remove PCR duplicate reads from the aligned BAM files before gene-level read counting.

Removing PCR duplicates helps reduce potential biases caused by amplification during library preparation.

## Input

BAM files generated by RNA STAR.

## Parameters

MarkDuplicates was performed using the default settings.

No custom parameters were specified.

## UMI

The RNA-seq library did not contain Unique Molecular Identifiers (UMIs).

Therefore, UMI-based duplicate removal was not performed.

## Output

Deduplicated BAM files were generated and used as input for featureCounts.

## Workflow

```text
FASTQ
↓
RNA STAR
↓
BAM
↓
MarkDuplicates
↓
Deduplicated BAM
↓
featureCounts
```
