# Galaxy RNA-seq Analysis

RNA-seq preprocessing, alignment, duplicate removal, and read counting were performed using Galaxy.

## Analysis workflow

```text
FASTQ
↓
FastQC
↓
fastp (14-month samples only)
↓
RNA STAR
↓
MarkDuplicates
↓
featureCounts
↓
Column Join
↓
Count matrix
```

## Samples

Four experimental groups were analyzed:

- 6-month-old WT
- 6-month-old KO
- 14-month-old WT
- 14-month-old KO

## Quality control

FASTQ files were initially evaluated using FastQC.

Adapter contamination was detected in the 14-month-old samples. Therefore, adapter trimming and quality filtering were performed using fastp for these samples.

The 6-month-old samples were processed without fastp because no major adapter contamination was detected.

## Adapter trimming and quality filtering

For paired-end reads, fastp was performed using the following parameters:

```bash
--detect_adapter_for_pe
--qualified_quality_phred 20
--length_required 36
-w 4
```

## Alignment

Reads were aligned to the mouse reference genome using RNA STAR.

## Duplicate removal

PCR duplicates were removed using MarkDuplicates.

## Read counting

Gene-level read counts were generated using featureCounts.

## Count matrix generation

Count files generated by featureCounts were combined using Column Join in Galaxy.

Separate count matrices were generated for the following comparisons:

1. 6-month WT vs KO
2. 14-month WT vs KO
3. WT 6-month vs 14-month
4. KO 6-month vs 14-month

The resulting count matrices were subsequently analyzed using DESeq2 in R.
