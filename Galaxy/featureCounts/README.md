# featureCounts

Gene-level read counting was performed using featureCounts on the deduplicated BAM files.

## Purpose

featureCounts was used to assign aligned RNA-seq reads to genes and generate gene-level read count files for downstream differential expression analysis.

## Input

Deduplicated BAM files generated by MarkDuplicates.

## Annotation

The same GTF annotation used for RNA STAR alignment was used for featureCounts.

- Gene annotation: gencode.vM10.annotation.gtf

## Parameters

The following settings were used:

- Strand specificity: Unstranded
- Read type: Paired-end
- Paired-end counting: Count paired-end reads as if they were individual reads

Other parameters were left at their default settings.

## Output

Gene-level count files were generated for each sample.

The resulting count files were subsequently combined using Column Join in Galaxy to generate count matrices.

## Count matrix generation

The featureCounts output files were combined using Column Join.

Four count matrices were generated for the following differential expression comparisons:

1. 6-month WT vs KO
2. 14-month WT vs KO
3. WT 6-month vs 14-month
4. KO 6-month vs 14-month

These count matrices were subsequently analyzed using DESeq2 in R.

## Workflow

```text
RNA STAR
↓
BAM
↓
MarkDuplicates
↓
Deduplicated BAM
↓
featureCounts
↓
Gene-level count files
↓
Column Join
↓
Count matrix
↓
DESeq2
```
