# Count Matrices

Gene-level count matrices generated from featureCounts output were used as input for downstream differential expression analysis with DESeq2.

## Generation

The count files generated by featureCounts were combined using Column Join in Galaxy.

Each row represents a gene, and each column represents a sample.

## Count matrices

Four count matrices were generated for the following comparisons:

| File | Comparison |
|---|---|
| `6month_WT_vs_KO_count.csv` | 6-month WT vs KO |
| `14month_WT_vs_KO_count.csv` | 14-month WT vs KO |
| `WT_6month_vs_14month_count.csv` | WT 6-month vs 14-month |
| `KO_6month_vs_14month_count.csv` | KO 6-month vs 14-month |

## Downstream analysis

The count matrices were imported into R and analyzed using DESeq2.

The following steps were performed:

1. Import count matrix
2. Convert count data to numeric matrix
3. Remove the non-numeric row present in the original count matrix
4. Create a DESeqDataSet
5. Filter genes with total counts below 10
6. Normalize and estimate dispersion using DESeq2
7. Perform differential expression testing
8. Identify differentially expressed genes (DEGs)

## Notes

The count matrices contain gene-level read counts generated by featureCounts.

Raw FASTQ and BAM files are not included in this repository because of their large file size.
