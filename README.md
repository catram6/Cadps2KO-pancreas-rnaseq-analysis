# Pancreatic RNA-seq Analysis

## Overview

This repository contains the RNA-seq analysis performed to investigate gene expression changes associated with aging and genotype in mouse pancreatic tissue.

The study focuses on comparing wild-type (WT) and knockout (KO) mice at two different ages.

The four experimental groups were:

- 6-month-old WT
- 6-month-old KO
- 14-month-old WT
- 14-month-old KO

The analysis was performed using Galaxy, R, and Python.

The analysis of the current datasets has been completed, while the overall research project is ongoing.

## Background

The pancreas is composed of two functionally distinct compartments: the 
exocrine acinar tissue, which secretes digestive enzymes (e.g., amylase, 
trypsin) into the gastrointestinal tract, and the endocrine islets, which 
secrete hormones (e.g., insulin, glucagon) into the bloodstream. 
Dysfunction of these compartments underlies pancreatitis and diabetes, 
respectively, and the prevalence of both conditions is rising in an aging 
society.

Cadps2 (CAPS2) is a protein that promotes exocytosis of secretory 
granules. Cadps2-knockout (KO) mice develop exocrine pancreatic 
insufficiency as a result of impaired granule exocytosis. This study 
aimed to elucidate the age-related progression of pancreatic pathology 
and gene expression changes in Cadps2-KO mice.

Histological analysis of KO pancreata revealed age-progressive acinar 
cell atrophy and death, interstitial fibrosis, adipose replacement, 
immune cell infiltration, and acinar-to-ductal metaplasia (ADM) — a 
pathological profile reminiscent of human chronic pancreatitis. To 
capture transcriptional changes at stages considered critical for the 
onset and prevention of pancreatic disease, RNA-seq analysis was 
performed at 6 months of age (young adulthood) and 14 months of age 
(middle age). The results showed that, in addition to the gene 
expression changes associated with normal pancreatic aging seen in WT 
mice, KO mice exhibited additional transcriptional changes associated 
with the progression of chronic pancreatitis and with compensatory 
responses to it.

## Experimental design

Four pairwise comparisons were performed:

1. 6-month WT vs KO
2. 14-month WT vs KO
3. WT 6-month vs 14-month
4. KO 6-month vs 14-month

These comparisons were used to investigate genotype-dependent and age-dependent changes in pancreatic gene expression.

## Galaxy analysis

The initial processing of FASTQ files was performed using Galaxy.

### 1. Quality control

FASTQ files were evaluated using FastQC.

For the 14-month-old samples, adapter contamination was detected.

Therefore, adapter trimming and quality filtering were performed using fastp.

The 6-month-old samples were processed without fastp because no major adapter contamination was detected.

### 2. Adapter trimming with fastp

Paired-end reads were processed using fastp.

The parameters used were:

```bash
    --detect_adapter_for_pe
    --qualified_quality_phred 20
    --length_required 36
    -w 4
```

The fastp command used for the analysis was:

```bash
    fastp -i input_R1.fq.gz -I input_R2.fq.gz -o trimmed_R1.fq.gz -O trimmed_R2.fq.gz --detect_adapter_for_pe --qualified_quality_phred 20 --length_required 36 -w 4
```

### 3. Alignment with RNA STAR

Reads were aligned to the mouse reference genome using RNA STAR.

Parameters included:

- Read type: paired-end
- Reference genome: mm10
- Gene model: gencode.vM10.annotation.gtf
- Length of the genomic sequence around annotated junctions: 149

Other parameters were left at their default settings unless otherwise specified.

### 4. Removal of duplicate reads

PCR duplicates were removed using MarkDuplicates.

The default parameters were used.

### 5. Gene-level read counting

Gene-level read counts were generated using featureCounts.

Parameters included:

- Read type: paired-end
- Strand specificity: unstranded
- Paired-end reads were counted as individual reads
- Gene annotation: gencode.vM10.annotation.gtf

The same GTF annotation used for RNA STAR was used for featureCounts.

### 6. Count matrix generation

Count files generated by featureCounts were combined using Column Join in Galaxy.

Four count matrices were generated corresponding to the four differential expression comparisons.

The resulting count matrices were subsequently analyzed in R using DESeq2.

## R: Differential expression analysis

Differential expression analysis was performed using DESeq2.

Four independent DESeq2 analyses were performed.

The general workflow was:

```r
    library(DESeq2)

    samples <- read.csv("sample_table.csv")

    samples$condition <- factor(
        samples$condition,
        levels = c("reference", "comparison")
    )

    counts_df <- read.csv(
        "count_matrix.csv",
        row.names = 1
    )

    count_matrix <- as.matrix(counts_df)

    storage.mode(count_matrix) <- "numeric"

    count_matrix <- na.omit(count_matrix)

    dds <- DESeqDataSetFromMatrix(
        countData = count_matrix,
        colData = samples,
        design = ~ condition
    )

    keep <- rowSums(counts(dds)) >= 10

    dds <- dds[keep, ]

    dds <- DESeq(dds)

    res <- results(dds)
```

### Count matrix preprocessing

The original count matrices contained an additional non-numeric row.

When converting the count matrix to numeric format, this resulted in NA values.

These rows were removed using:

```r
    count_matrix <- na.omit(count_matrix)
```

This preprocessing step was applied to the count matrices used for the DESeq2 analyses.

### Filtering

Genes with a total count below 10 across all samples were removed:

```r
    keep <- rowSums(counts(dds)) >= 10
    dds <- dds[keep, ]
```

### DEG identification

DEGs were identified using an adjusted p-value threshold of:

    padj < 0.05

Upregulated genes were defined as:

    padj < 0.05 & log2FoldChange > threshold

Downregulated genes were defined as:

    padj < 0.05 & log2FoldChange < -threshold

The thresholds used for each comparison were:

| Comparison | Adjusted p-value | log2FC threshold |
|---|---:|---:|
| 6-month WT vs KO | < 0.05 | ｜log2FC｜ > 1 |
| 14-month WT vs KO | < 0.05 | ｜log2FC｜ > 1 |
| WT 6-month vs 14-month | < 0.05 | ｜log2FC｜ > 2 |
| KO 6-month vs 14-month | < 0.05 | ｜log2FC｜ > 2 |

The log2FC threshold was increased to 2 for the aging comparisons because the number of DEGs was large and exceeded the number of genes that could be submitted to the subsequent Metascape analysis.

### DEG results

The final DEG counts were:

| Comparison | Upregulated | Downregulated | Total |
|---|---:|---:|---:|
| 6-month WT vs KO | 1,871 | 1,813 | 3,684 |
| 14-month WT vs KO | 701 | 448 | 1,149 |
| WT 6-month vs 14-month | 1,490 | 1,090 | 2,580 |
| KO 6-month vs 14-month | 1,221 | 835 | 2,056 |

The complete DESeq2 results and DEG lists are stored in the results/ directory.

## Volcano plots

Volcano plots were generated using Python.

The plots visualize:

- log2 fold change
- adjusted p-value
- significantly upregulated genes
- significantly downregulated genes

Standard volcano plots were generated for:

- 6-month KO vs WT
- 14-month KO vs WT
- WT 14-month vs 6-month

An additional volcano plot was generated for the KO aging comparison:

- KO 14-month vs 6-month

For the KO aging comparison, selected genes associated with pancreatic phenotypes were highlighted.

The highlighted genes were classified into the following categories:

- Acinar / secretory granule
- Exocytosis machinery
- Fibrosis / immune infiltration
- ADM / ductal

Cadps2 was excluded from the highlighted category plot to allow visualization of other phenotype-associated genes.

The Python scripts used to generate the volcano plots are stored in the Python/ directory.

The resulting plots are stored in the results/ directory.

## DEG overlap analysis

The DEG lists obtained from the four comparisons were compared to identify genes shared between different experimental comparisons.

The overlap analysis considered both:

- whether a gene was identified as a DEG
- whether the direction of regulation was consistent

For comparisons involving the KO aging dataset, UP and DOWN genes were matched according to their direction of change.

Based on the overlap patterns, the DEGs were divided into seven subgroups.

### Seven DEG subgroups

| Subgroup | Definition |
|---|---|
| Subgroup 1 | KO aging and WT aging DEGs shared with consistent UP/DOWN direction |
| Subgroup 2 | DEGs shared by KO aging, WT aging, and 14-month WT vs KO |
| Subgroup 3 | DEGs shared by KO aging, WT aging, and 6-month WT vs KO |
| Subgroup 4 | DEGs shared by KO aging, WT aging, 14-month WT vs KO, and 6-month WT vs KO |
| Subgroup 5 | DEGs shared by KO aging, 14-month WT vs KO, and 6-month WT vs KO |
| Subgroup 6 | DEGs shared by KO aging and 14-month WT vs KO |
| Subgroup 7 | DEGs specific to the KO aging comparison |

No DEG was identified in a subgroup corresponding exclusively to KO aging and 6-month WT vs KO.

Therefore, the final overlap analysis consisted of seven subgroups.

### Subgroup sizes

The resulting subgroup sizes were:

| Subgroup | Total | UP in KO aging | DOWN in KO aging |
|---|---:|---:|---:|
| Subgroup 1 | 757 | 407 | 350 |
| Subgroup 2 | 28 | 27 | 1 |
| Subgroup 3 | 162 | 54 | 108 |
| Subgroup 4 | 31 | 17 | 14 |
| Subgroup 5 | 3 | 2 | 1 |
| Subgroup 6 | 161 | 152 | 9 |
| Subgroup 7 | 914 | 562 | 352 |

The subgroup classification was subsequently used for functional enrichment analysis.

## Functional enrichment analysis

Functional enrichment analyses were performed independently for each of the seven DEG subgroups.

### Metascape

Each subgroup was analyzed using Metascape to investigate the biological characteristics of the genes.

### ChIP-Atlas

ChIP-Atlas enrichment analysis was performed for each DEG subgroup.

The analysis was used to investigate:

- potential transcription factors
- transcriptional regulation
- regulatory mechanisms associated with the DEG subgroups

Metascape and ChIP-Atlas results were used together to investigate the biological characteristics and potential regulatory mechanisms associated with pancreatic aging and disease-related phenotypes.

The enrichment analysis results are stored in the results/ directory.

## Reproducibility

This repository documents the computational workflow used for the analysis, including:

- FASTQ quality control
- adapter trimming
- genome alignment
- duplicate removal
- gene-level read counting
- count matrix generation
- DESeq2 analysis
- DEG criteria
- DEG overlap analysis
- volcano plot generation
- Metascape enrichment analysis
- ChIP-Atlas enrichment analysis

Raw FASTQ files and large intermediate files are not included in this repository.

The repository is intended to provide a record of the analysis workflow and facilitate reproducibility of the computational analysis.

## Analysis status

The RNA-seq analyses of the current four experimental groups (6-month-old WT, 6-month-old KO, 14-month-old WT, and 14-month-old KO) have been completed, including differential expression analysis, DEG overlap analysis, subgroup classification, and downstream enrichment analyses.

This repository currently documents the analysis performed using these datasets. However, the overall research project is ongoing, and additional datasets will be incorporated as the study progresses.

Future work will extend the analysis by integrating newly generated or available datasets to further investigate the molecular mechanisms underlying pancreatic aging and disease-related phenotypes. Candidate genes and pathways identified through the integrated analyses will be further investigated and experimentally validated.
